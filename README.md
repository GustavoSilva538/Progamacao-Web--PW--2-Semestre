Este repositório é dedicado ao armazenamento e organização de todos os materiais de estudo, exercícios práticos e entregas da disciplina de **Programação Web (PW)**, cursada no 2º semestre de Análise e Desenvolvimento de Sistemas (ADS). 

O foco desta disciplina é a construção de interfaces web e o domínio da tríade fundamental do desenvolvimento front-end: a estruturação semântica, a estilização visual e a interatividade dinâmica.
